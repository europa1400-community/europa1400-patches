monitorfix - choose the monitor for Europa 1400: The Guild (Die Gilde) Gold
===========================================================================

The game remembers its Direct3D choice by the graphics card only, so on a PC with several monitors on one card it
always starts on the last one. monitorfix is a small d3d8.dll that sits next to the game exe and shows the game
exactly one monitor.

Install: extract into the game directory (the folder with the game exe and game.ini): d3d8.dll, monitorfix.ini.
Choose:  monitor=N in monitorfix.ini (1 = main display, 2 = second, ...; 0 = off). monitorfix.log (written next to
         the dll at every start) lists the monitors and which number each one has.
Remove:  delete d3d8.dll, monitorfix.ini and monitorfix.log.

The europa1400-manager installs and configures it for you.
